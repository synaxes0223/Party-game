# Audio files

Drop song pairs here as MP3 files, e.g.:
  - normal-song1.mp3
  - imposter-song1.mp3

Referenced in findTheImposter.js SONG_PAIRS list.
For the prototype, two short placeholder tones (generated via ffmpeg)
are used so you can test the sync + imposter mechanic without real
music files yet. Swap in real songs later — same file structure.
